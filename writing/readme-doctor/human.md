# Readme-Doctor - Human Guide

Diagnose READMEs: missing promise, install friction, stale bits.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Stress-tests a README like a user would: cold-runs the install commands, times the quickstart, checks every claim — then reports what broke and what confused.

## When to use it

Before launching anything others will use; periodic hygiene pass. Triggers: readme review, first impression, install broken.

## When NOT to use it

Internal repos with three developers can survive lean READMEs. Don't gold-plate pre-product exploration.

## How you know it worked

Someone unfamiliar installs and runs successfully using nothing but the README.
