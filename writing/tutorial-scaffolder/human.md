# Tutorial-Scaffolder - Human Guide

Structure tutorials: promise, steps, checkpoints, payoff.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Builds tutorials that actually work for strangers: explicit promise, small verifiable wins, and — critically — documented fixes for the errors learners will actually hit at each step.

## When to use it

Onboarding flows, feature adoption, teaching recurring concepts. Triggers: tutorial, getting started, walkthrough.

## When NOT to use it

Reference material isn't a tutorial. Don't scaffold what a single good example communicates.

## How you know it worked

Fresh-eyes testers finish unaided; their stumbles became new failure-path entries.
