# Tutorial-Scaffolder

Structure tutorials: promise, steps, checkpoints, payoff..

## When to Use

Knowledge exists in experts' heads; newcomers keep needing the same walkthrough that doesn't exist.

## Workflow

1. Define the promise precisely: what will the learner be able to DO afterward?
2. Map prerequisites ruthlessly; link out rather than inline-explain the world.
3. Structure steps with checkpoints: small wins every few minutes, each verifiable by the learner.
4. Write the failure paths: common errors AT EACH STEP with fixes (tutorials die on unstated assumptions).
5. Test on someone with fresh eyes matching the target audience; revise where they stall.

## Pitfalls

Teaching the expert's mental model before building the learner's. Steps that skip 'obvious' bits (the exact bits beginners trip on). No checkpoints so learners can't tell if they're on track. Testing on colleagues who already know.

## Verification

Three consecutive fresh-eyes testers complete without external help; stall points get fixed between tests, not explained away.

## Inputs

- Task context: expert knowledge, target learner profile

## Outputs

- tested tutorial with checkpoints and failure-path fixes
