# Onboarding-Doc-Audit - Human Guide

Audit onboarding docs against a newcomer's actual first day.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Follows a real newcomer through onboarding against the docs, logging exactly where documentation fails them — then fixes both content and findability.

## When to use it

Recurring new-hire questions, pre-scaling team growth. Triggers: onboarding, documentation audit, ramp-up.

## When NOT to use it

Don't audit without a real newcomer available (your own context lies). Solo projects can rely on fresh-eyes friends.

## How you know it worked

The NEXT person onboarded hits measurably fewer walls; their log feeds the next round.
