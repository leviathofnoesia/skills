# Translation-Handoff-Kit - Human Guide

Package copy for translators: context, glossary, constraints.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Packages copy for translators the way they actually need: every string carrying its screen context, glossary attached, culture-traps flagged — so translations come back right the first time.

## When to use it

Any localization effort. Triggers: i18n handoff, translation package, locale prep.

## When NOT to use it

One-language products skip this. Machine-translation drafts still need this kit for human review.

## How you know it worked

Zero clarification rounds during translation; critical-flow review catches no context errors.
