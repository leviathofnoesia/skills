# Release-Note-Editor - Human Guide

Edit raw notes into scannable release communications.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Edits raw release drafts into sharp communications: cut per-audience, verify every claim against actual changes, make breaking changes impossible to miss.

## When to use it

Shipping releases to real stakeholders. Triggers: release announcement, edit release notes.

## When NOT to use it

Don't invent excitement absent from the changes. Internal-only releases need only the engineering log.

## How you know it worked

Ops finds breaking changes instantly; users find capabilities instantly; nothing claimed that didn't happen.
