# Changelog-Narrator - Human Guide

Turn diff sets into user-facing changelog entries.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Converts developer-facing merge histories into user-facing narratives: grouped by impact, led by outcomes, honest about behavior changes.

## When to use it

Every release with user-visible changes. Triggers: release notes, changelog, what's new.

## When NOT to use it

Internal-only tools may want terse logs. Security-sensitive details belong in advisories, not marketing notes.

## How you know it worked

Users navigate new version without asking 'where did X go' in support channels.
