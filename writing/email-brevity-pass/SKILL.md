# Email-Brevity-Pass

Compress professional email while keeping asks explicit..

## When to Use

Professional emails that bury asks in context, or run long enough to lose readers.

## Workflow

1. Lead with the ask or headline: first sentence states what you need/announce.
2. Context budget: include ONLY background the recipient lacks (check their last email — don't re-explain their own project to them).
3. Convert paragraphs to scannable structure: bullets for lists, bold for deadlines/dates.
4. Make the ask actionable: specific request, deadline, and what happens if no response.
5. Delete sentences surviving only from drafting habit ('I hope this finds you well' counts).

## Pitfalls

Brevity that cuts necessary context (recipient now has to ask). So blunt it damages relationships — brevity ≠ curtness. Multiple unrelated asks in one email guarantee partial completion.

## Verification

Recipient action is unambiguous within 10 seconds of opening; thread length drops because clarification rounds vanish.

## Inputs

- Task context: draft email, recipient context

## Outputs

- compressed email preserving intent and courtesy
