# Threat-Model-Lite - Human Guide

Lightweight STRIDE threat modeling sized to project stakes.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Lightweight threat modeling: enumerate assets and trust boundaries, walk STRIDE, rate honestly, assign owners — sized to matter without formal-methods paralysis.

## When to use it

New features touching auth/payments/PII, system redesigns. Triggers: threat model, security review, STRIDE.

## When NOT to use it

Not a compliance checkbox or pen-test replacement. Toy projects with no real users can skip.

## How you know it worked

Security review findings were mostly already on your list; every survivor has an owner.
