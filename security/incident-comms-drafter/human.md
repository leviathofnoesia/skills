# Incident-Comms-Drafter - Human Guide

Incident communications: fast ack, kept cadence, facts only.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Incident communication discipline: fast first ack, kept update promises, facts-only during firefighting, honest quantified summary after — audience-matched throughout.

## When to use it

Any user-visible incident. Triggers: status update, incident comms, outage notification.

## When NOT to use it

Purely internal infra blips may need only the retro. Don't communicate speculatively before facts exist.

## How you know it worked

Zero retracted statements; stakeholders cite the comms as competent, not the incident itself.
