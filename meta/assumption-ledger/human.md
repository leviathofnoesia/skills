# Assumption-Ledger - Human Guide

Track assumptions explicitly and revisit them before shipping.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Writes down what a plan silently believes, ranks beliefs by danger-if-wrong, and schedules the cheapest tests that could kill them before they cost real money.

## When to use it

Before committing weeks to a plan built on guesses. Triggers: assumptions, risks, validation.

## When NOT to use it

Not for listing risks you can do nothing about. Don't ledger trivia.

## How you know it worked

The ledger has scars: assumptions marked killed, with visible plan changes that resulted.
