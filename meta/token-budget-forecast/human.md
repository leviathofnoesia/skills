# Token-Budget-Forecast - Human Guide

Estimate token cost of a plan before executing it.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Estimates the token/cost footprint of a plan BEFORE running it, using your own logged history to calibrate — then redesigns expensive steps up front.

## When to use it

Expensive autonomous tasks or tight budgets. Triggers: cost estimate, token budget, planning spend.

## When NOT to use it

Trivial tasks don't need forecasting theater. Don't optimize what you never measure — log actuals first.

## How you know it worked

Predicted vs actual converges across runs; no more bill surprises.
