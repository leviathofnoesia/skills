# Context-Pruning-Pass - Human Guide

Drop stale conversation context before long tasks to save budget.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Cleans an agent's working memory like desk decluttering: keeps decisions and results, compresses noise into brief notes, discards superseded attempts.

## When to use it

Sessions get long and drift-y or costs spike. Triggers: context window, pruning, compaction.

## When NOT to use it

Don't prune mid-operation. Not for short tasks where full history is cheap and useful.

## How you know it worked

After pruning, work continues seamlessly and the token meter visibly slows.
