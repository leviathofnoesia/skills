# Progress-Heartbeat - Human Guide

Emit structured progress notes during long autonomous runs.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Structured status updates during long agent runs: step counts, milestones hit, ETAs, anomalies — so silence never leaves anyone guessing.

## When to use it

Any run longer than a coffee break. Triggers: progress updates, long-running task, heartbeat.

## When NOT to use it

Short tasks don't need ceremony. Content-free 'still going' spam helps nobody.

## How you know it worked

Mid-run, a stranger reads the last three heartbeats and accurately describes the state.
