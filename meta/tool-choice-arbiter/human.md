# Tool-Choice-Arbiter - Human Guide

Pick the cheapest sufficient tool for each subtask step.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Teaches agents to reach for the cheapest tool that works: read before search, search before browse — with logged reasoning so the ladder improves over time.

## When to use it

Agent runs feel expensive or scattered. Triggers: tool selection, efficiency, cost control.

## When NOT to use it

Correctness outranks cost — never ladder away from the right tool. Skip for tiny tasks where choice overhead exceeds savings.

## How you know it worked

Same task, same result, smaller bill; every expensive-tool call traces to a documented reason.
