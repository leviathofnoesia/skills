# Artifact-Lineage - Human Guide

Record which files/artifacts produced which outputs and why.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Provenance stamps for work products: every artifact records what inputs and steps created it, so months later you know if it's trustworthy or stale.

## When to use it

Pipelines producing many interdependent artifacts. Triggers: provenance, lineage, reproducibility.

## When NOT to use it

One-off files don't need lineage bureaucracy. Don't hash volatile inputs expecting stable IDs.

## How you know it worked

Pick any old artifact: its sidecar tells the full origin story without tribal memory.
