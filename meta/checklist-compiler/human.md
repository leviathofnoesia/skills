# Checklist-Compiler - Human Guide

Compile recurring workflows into executable checklists.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Turns recurring manual workflows into battle-ready checklists by shadowing a real execution — capturing the tacit steps memory always forgets.

## When to use it

Repeated workflows with missable steps: releases, onboarding, monthly ops. Triggers: checklist, procedure, runbook-lite.

## When NOT to use it

If it happens daily and is deterministic, automate instead. Checklists aren't training wheels for skills people should build.

## How you know it worked

Stranger test passes: someone unfamiliar completes the flow correctly first try.
