# Prompt-Contract-Authoring - Human Guide

Write explicit input/output contracts for reusable prompts.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Turns reusable prompts into reliable tools by writing down exactly what goes in, what must come out, and how to tell failure — like an API spec for words.

## When to use it

Any prompt used more than twice or shared between people. Triggers: prompt template, contract, reusable prompt.

## When NOT to use it

One-off prompts don't need ceremony. Don't contract so hard the model can't handle reasonable variation.

## How you know it worked

Hand the contract to someone else (or another agent): output quality holds.
