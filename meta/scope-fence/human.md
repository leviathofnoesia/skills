# Scope-Fence - Human Guide

Detect and stop scope creep mid-task with a written fence.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

A written boundary for what a task IS — so 'while we're here' impulses get parked and tracked instead of silently doubling the work.

## When to use it

Any task prone to wandering: refactors near tempting code, shared files. Triggers: scope creep, focus, while-we're-here.

## When NOT to use it

Exploration spikes legitimately need fences lifted — renegotiate rather than smuggle. Don't fence bug fixes into rigidity.

## How you know it worked

Diff review shows every hunk maps to the stated goal; parking-lot items became real tickets.
