# Dataset-Provenance - Human Guide

Document where data came from and what licenses apply.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Documentation discipline so datasets stay trustworthy: exactly where data came from, what touched it, under what license — attached to the data itself forever.

## When to use it

Any dataset others will consume or that feeds models/reports. Triggers: data lineage, provenance, where did this come from.

## When NOT to use it

Throwaway analysis data can skip ceremony. Don't document data you'd be ashamed to document (that's a different problem).

## How you know it worked

Dataset copy arrives with sidecar intact; reconstruction attempt succeeds.
