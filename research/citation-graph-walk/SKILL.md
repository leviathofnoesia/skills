# Citation-Graph-Walk

Follow citation chains forward/backward to map a topic's core..

## When to Use

Mapping a topic's intellectual core, finding the foundational work behind current practice.

## Workflow

1. Start from 2-3 known-relevant recent papers.
2. Walk BACKWARD through their reference lists; note which references appear everywhere (the anchors).
3. Walk FORWARD via cited-by to find the newest developments and critiques.
4. Identify the debate structure: which papers cite each other approvingly vs critically.
5. Output the core reading set: anchors + best recent synthesis + sharpest critique.

## Pitfalls

Mistaking citation count for quality (survey papers inflate). Following one citation lineage into an echo cluster. Ignoring non-English literature where relevant.

## Verification

The anchor set matches what domain experts call canonical; forward walk surfaced at least one post-12-month critique you hadn't seen.

## Inputs

- Task context: seed papers, scholarly search access

## Outputs

- core reading list mapped by influence and critique
