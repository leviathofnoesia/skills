# Experiment-Power-Check - Human Guide

Sanity-check sample size and effect size before running tests.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Sanity-checks experiments before they burn weeks: can this test actually detect an effect that matters, given real traffic? Prevents the classic underpowered-run-anyway disaster.

## When to use it

Before ANY experiment. Triggers: sample size, power analysis, AB test planning.

## When NOT to use it

Exploratory probes can skip rigor if labeled exploratory. Don't power-check qualitative research with these formulas.

## How you know it worked

Pre-registration document predates the data; the effect threshold was chosen for business relevance.
