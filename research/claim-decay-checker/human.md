# Claim-Decay-Checker - Human Guide

Check if a cited fact is superseded or retracted.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Audits old documents for facts that quietly expired: superseded statistics, retracted studies, claims whose context shifted. Stamps what's still safe to repeat.

## When to use it

Reusing last year's research, recycling decks, updating docs. Triggers: outdated, stale claim, refresh.

## When NOT to use it

Historical statements about the past don't decay ('in 2019 X was true' stays true). Don't churn stable mathematics.

## How you know it worked

The output table shows real finds: revised numbers, retracted sources — not a rubber-stamp pass.
