# Oncall-Transition-Kit - Human Guide

Structured handoffs: open incidents, risks, quiet wins.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Structured oncall handoffs that actually transfer situational awareness: written state before the call, explicit acknowledgment of each item, escalation thresholds stated not implied.

## When to use it

Every oncall rotation. Triggers: oncall handoff, shift transition, pager transfer.

## When NOT to use it

Solo operators skip. Don't replace incident docs with handoff notes — link them.

## How you know it worked

Incoming handles the shift's first surprise without calling the outgoing person.
