# Runbook-Author - Human Guide

Write runnable runbooks: symptoms, checks, actions, rollback.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Writes operational procedures built for 3am brains: symptom-indexed, command-exact, showing what output to expect at each step, with explicit stop-and-escalate triggers.

## When to use it

Anything that pages humans repeatedly. Triggers: runbook, SOP, operational procedure.

## When NOT to use it

One-time procedures don't need runbook investment. Don't document what full automation should own instead.

## How you know it worked

Drill passes: stranger resolves the staged scenario using only the document.
