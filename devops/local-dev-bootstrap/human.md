# Local-Dev-Bootstrap - Human Guide

Make 'clone to running' under 10 minutes with one command.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Compresses days of setup archaeology into one command that works on clean machines — pinned versions, seeded data, offline-capable defaults, verified continuously so it stays true.

## When to use it

Onboarding pain, contributor growth, returning-after-months confusion. Triggers: dev setup, bootstrap script, getting started.

## When NOT to use it

Single-developer projects may tolerate informal setups. Don't automate what should be deleted instead.

## How you know it worked

Fresh VM clone-to-running under 10 minutes using only repo instructions.
