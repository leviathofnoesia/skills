# Meeting-Decision-Capture

Capture meeting decisions with owners before memories diverge..

## When to Use

Meetings produce conversation but not recorded outcomes; the same topics return weekly.

## Workflow

1. Capture live in a decision log: DECISION / OWNER / DATE columns, nothing else.
2. Separate decisions from discussions explicitly; discussions get one summary line max.
3. Every decision gets an owner who acknowledges it IN the meeting, not after.
4. Action items get deadlines and land in the tracker before the meeting ends.
5. Publish within an hour while memories align; link previous log for continuity.

## Pitfalls

Minutes as transcript (nobody rereads). Decisions without owners (revisited forever). Capturing what was SAID instead of what was DECIDED. Publishing days later when everyone's memory diverged.

## Verification

Next meeting opens by reviewing last log: zero re-litigated decided topics; every action item traceable to its source meeting.

## Inputs

- Task context: live meeting access

## Outputs

- decision log published within the hour
