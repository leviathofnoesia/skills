# Priority-Tradeoff-Matrix

Weighted prioritization with axes agreed before scoring..

## When to Use

Everything feels urgent; stakeholders each insist THEIR item is obviously next.

## Workflow

1. List competing items with their true champions (not just requesters — who benefits?).
2. Score on agreed axes: value-if-done, cost-of-delay, effort, dependency unlock potential.
3. Weight axes BEFORE scoring items (prevents retrofitting weights to preferred answer).
4. Force rank; identify the cheapest-item-first trap (easy wins crowding out important ones).
5. Publish the matrix WITH the decision; revisited rankings build trust in the method.

## Pitfalls

Weights chosen to justify predetermined answers. Effort dominating value (busy-ness bias). Matrix as weapon ending debate rather than informing it. Scoring precision theater on unknown estimates (use t-shirt sizes).

## Verification

Stakeholders accept the NEXT prioritization round without relitigating the method; the top-ranked item demonstrably mattered when done.

## Inputs

- Task context: competing items, stakeholder input

## Outputs

- weighted ranking with published rationale
