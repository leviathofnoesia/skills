# Weekly-Review-Loop

Fixed weekly ritual: wins, misses, one process experiment..

## When to Use

Weeks blur together; lessons evaporate; Monday starts feel like groundhog day.

## Workflow

1. Fixed 30-minute slot, Friday afternoon: review wins, misses, surprises from the week's notes.
2. Check metrics you claim to track; note trends without obsessing.
3. Extract ONE process improvement attempt for next week (small enough to actually try).
4. Clear decks: inbox to zero-ish, calendar prepped, task list triaged for Monday-start.
5. Log the review in one place; patterns across weeks become visible quarterly.

## Pitfalls

Reviews becoming planning marathons (30 minutes, hard stop). Skipping during busy weeks (exactly when most valuable). Improvements attempted never reviewed. Guilt spirals over missed items instead of adjustment.

## Verification

Streak count of consecutive reviews grows; quarterly read of logs shows at least one adopted improvement per month.

## Inputs

- Task context: week's notes/calendar/task history

## Outputs

- logged review + next-week improvement attempt
