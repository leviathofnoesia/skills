# Pr-Description-Forge - Human Guide

Write PR descriptions reviewers actually need: intent, risk, test.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

A template-driven way to write PR descriptions carrying exactly what reviewers need: intent, context links, risk, test proof, and where to look hardest.

## When to use it

Every non-trivial PR. Triggers: pull request, description, review prep.

## When NOT to use it

Skip ceremony for typo-level diffs — one line suffices. Don't fake structure when there's no risk section content.

## How you know it worked

Reviewer's first comment is about the change's substance, never about understanding what changed.
