# Dependency-License-Audit - Human Guide

Inventory dependency licenses and flag copyleft/commercial risk.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Maps every dependency (including transitive ones) to its actual license and flags legal risk for how YOU distribute software.

## When to use it

Before open-sourcing, enterprise deals, or mass-adding packages. Triggers: license audit, GPL, compliance, attribution.

## When NOT to use it

Not legal advice — escalate strong-copyleft-in-closed-product questions to counsel. Skip for throwaway prototypes.

## How you know it worked

No package in the tree has status 'unknown'; NOTICE file generates from data.
