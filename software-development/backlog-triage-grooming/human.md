# Backlog-Triage-Grooming - Human Guide

Turn a stale issue backlog into a ranked, actionable queue.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Mass-cleanup for rotten backlogs: bulk-close with honest reasons, merge duplicates, rank only what's near-term, and install a light recurring habit.

## When to use it

Quarterly, or when planning feels like lies. Triggers: backlog grooming, triage, stale issues.

## When NOT to use it

Not a one-person rewrite of every ticket's spec. Don't groom during incident week.

## How you know it worked

Team plans from the tracker again; closure comments survive audit without reopen storms.
