# Incident-Postmortem-Writer - Human Guide

Write blameless postmortems with timelines and action items.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Turns incidents into learning artifacts: evidence-based timelines, causes chased to process level, and action items with owners — never blame.

## When to use it

Within two days of any notable incident. Triggers: postmortem, RCA, incident review, outage.

## When NOT to use it

Not for trivial issues a runbook update covers. Never as a performance-review input.

## How you know it worked

Every finding traces to evidence (log/ticket), every action item has an owner and a date.
