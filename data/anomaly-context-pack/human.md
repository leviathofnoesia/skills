# Anomaly-Context-Pack - Human Guide

Pair each anomaly alert with the context needed to triage it.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Ships each alert with its investigation already started: affected scope, recent deploys, similar past incidents, and working runbook links — cutting time-to-triage to minutes.

## When to use it

Any paging system whose alerts start with 'what's going on?'. Triggers: alert context, actionable alerts, triage speed.

## When NOT to use it

Don't enrich noise — fix noisy alerts first. Info-only notifications don't need packs.

## How you know it worked

Next real page: responder confirms first-three-questions answered inline; triage timer visibly shorter.
