# Metric-Definition-Sheet - Human Guide

One canonical definition per metric with formula and owner.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Creates one authoritative definition per metric — exact formula, edge rules, owner — then forces every query and dashboard to match it, ending the 'whose number is right' wars.

## When to use it

Metric disputes, pre-funding diligence, dashboard proliferation. Triggers: metric definition, KPI alignment.

## When NOT to use it

Don't define metrics nobody uses yet. Historical comparisons may need dual-reporting during transitions — plan it.

## How you know it worked

Independent implementations match exactly; definition links appear on every consuming dashboard.
