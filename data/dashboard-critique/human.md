# Dashboard-Critique - Human Guide

Review dashboards: question first, chart honesty, load speed.. This guide explains what it does, when to reach for it, and how to
tell it worked.

## What this skill does

Reviews dashboards as decision tools rather than decoration: are the priority questions answered fastest, do charts lie, does it load fast enough to be used at all?

## When to use it

Quarterly hygiene, post-reorg ownership confusion, abandoned dashboards. Triggers: dashboard review, too many charts.

## When NOT to use it

Don't critique exploratory sandboxes by production standards. Executive-summary dashboards have different rules than ops consoles.

## How you know it worked

New team member answers the dashboard's core questions in one sitting; every surviving chart has a named consumer.
